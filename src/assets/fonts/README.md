# Share image font

`IBMPlexSans-Regular.ttf` comes from [IBM Plex](https://github.com/IBM/plex/blob/master/packages/plex-sans/fonts/complete/ttf/IBMPlexSans-Regular.ttf).
It supports Vietnamese and is bundled locally so share image generation needs no font service at request time.
